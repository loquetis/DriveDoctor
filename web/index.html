DriveDoctor 1.0.0

DriveDoctor only reads your drives. It never writes to them, never repairs and never formats. The one exception is the optional "Run short self-test" button, which asks the drive to run its own built-in quick check after you confirm.

Everything stays on this PC. Nothing is uploaded.

smartmontools (GPL)

DriveDoctor includes the unmodified smartctl program from smartmontools as a separate file and runs it to read SMART data.
